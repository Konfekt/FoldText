1. Introduction                                               *FoldText-intro*

FoldText sets 'foldtext' to |CustomFoldText()|, which shows for each closed
fold

- the first non-blank line of the fold, indented by 'shiftwidth' per fold
  level and truncated with ".." if it does not fit into the window,
- a delimiter that fills the gap up to the right window border, and
- the number of folded lines, absolute and as a percentage of the buffer.

The text fills the window up to its right border, taking into account the
fold, number and sign columns. It works well with `syntax` folds.

==============================================================================
2. Usage                                                      *FoldText-usage*

                                                            *CustomFoldText()*
CustomFoldText([{delim}])
        Return the fold text for the fold being drawn. The gap between the
        folded line and the fold size is filled with {delim}, a blank by
        default. {delim} may consist of several characters. For example: >
                set foldtext=CustomFoldText('·')
                set foldtext=CustomFoldText('-')
<
The plugin sets 'foldtext' to `CustomFoldText()` when it is loaded, unless it
is already set to `CustomFoldText(...)`. So, to use a different delimiter, set
'foldtext' to, say, `CustomFoldText('·')` in your vimrc.

                                                          *g:loaded_foldtext*
Set `g:loaded_foldtext` to 1 to prevent the plugin from loading.

3. Example settings                                         *FoldText-example*
>
        set foldmethod=syntax

        " Syntax folding
        let g:vimsyn_folding = 'af'
        let g:tex_fold_enabled = 1
        let g:xml_syntax_folding = 1
        let g:clojure_fold = 1
        let ruby_fold = 1
        let perl_fold = 1
        let perl_fold_blocks = 1

        set foldenable
        set foldlevel=0
        set foldlevelstart=0
        " specifies for which commands a fold will be opened
        set foldopen=block,hor,insert,jump,mark,percent,quickfix,search,tag,undo

        nnoremap <silent> zr zr:<c-u>setlocal foldlevel?<CR>
        nnoremap <silent> zm zm:<c-u>setlocal foldlevel?<CR>
        nnoremap <silent> zR zR:<c-u>setlocal foldlevel?<CR>
        nnoremap <silent> zM zM:<c-u>setlocal foldlevel?<CR>
<
See the README for a mapping that toggles the fold column.
